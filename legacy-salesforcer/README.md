# Archived Salesforcer Version

This directory preserves SOQL Quick 1.1.0, the original macOS-only implementation built with Swift/AppKit and an R backend using `salesforcer`.

It is retained as read-only migration history and a fallback reference. The supported application is the standalone Tauri/Rust implementation in the parent project. Do not build, install, or extend this version unless intentionally investigating legacy behavior.

The compiled legacy application is archived outside the repository under `~/Application Archives.noindex/` so Spotlight does not surface it alongside the supported application.
